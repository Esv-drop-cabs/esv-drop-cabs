Connect your Firebase project

This is a separate admin website. To sync fares to customers on every device, connect it to your own Firebase project. Your Firebase web config is not an admin password; never share your password or service-account private key.

Step 1: Create a Firebase project, enable Email/Password Authentication and Firestore, then paste the web app config here.
